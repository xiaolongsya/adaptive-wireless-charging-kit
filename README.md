# Adaptive Wireless Sealed-Battery Charging Kit

嘉立创比赛参赛项目 —— 磁吸对接的无线充电装置，用于机器狗等密封电池设备的便携式充电。

## 系统构成

```
        ┌────────────────┐      磁吸对准      ┌────────────────┐
        │  TX 充电座      │ ◄────────────────► │  RX 电池仓      │
        │  (5W Qi TX)     │      无线耦合      │  (含整流 MCU    │
        │  USB-C 供电     │                    │   + BMS)       │
        └────────────────┘                    └────────┬───────┘
                                                     │
                                             ┌───────┴────────┐
                                             │ 14500 / 18650  │
                                             │  3.7V Li-ion   │
                                             └────────────────┘
```

## 已锁定设计决策

| 项目 | 决策 | 备注 |
| --- | --- | --- |
| 功率目标 | 5W | 链路走通优先 |
| 应用场景 | 静止状态 | 不考虑震动脱落 |
| 外壳 | 密封、非金属 | PA12 / ABS / 树脂 |
| 双电池 | 14500 + 18650 | 同为 3.7V，容量不同 |
| 检测方式 | ID 电阻（XH2.54 4-pin） | 电压检测无效 |
| 充电算法 | CC-CV 4.2V | 自适应充电电流 |
| 充电 IC | CN3058E / TP4056 | PROG 切换电流档 |
| 保护 | DW01A + 8205A | 双重保护 |

## 风险与权衡（已确认）

- 效率：链路走通优先，效率低暂时接受
- 散热：待研究专题
- 震动脱落：项目以静止场景为主
- FOD / EMC：设计时兼顾
