## 模块清单（10 个）

| # | 模块 | 核心元件 | 作用 |
|---|---|---|---|
| 1 | RX 谐振 | PCB 线圈 + CBB 电容 | 拾取磁场，感应交流电压 |
| 2 | 整流滤波 | MB6S 整流桥 + π 滤波 | AC → DC 平滑输出 |
| 3 | RX 控制核心 | **BQ51013B** | 同步整流、LDO 输出、ASK 通信 |
| 4 | 电源管理 | AMS1117-3.3 LDO | 5V → 3.3V，给 MCU/LED 供电 |
| 5 | MCU 控制 | **STM32G030F6P6** | ID 检测、PROG 切换、LED 控制 |
| 6 | ID 检测 | 上拉电阻 + ID 脚 | 识别 14500/18650 电池类型 |
| 7 | PROG 切换 | 2× MOSFET + 2× R | 切换充电电流档位 |
| 8 | 充电管理 | **CN3058E** | CC-CV 充电曲线，电池充满判定 |
| 9 | 电池保护 | DW01A + 8205A | 过充/过放/过流/短路保护 |
| 10 | NTC 监测 | 10kΩ NTC 热敏电阻 | 电池温度监测 |
| 11 | 电池接口 | XH2.54-4P | 连接电池（V+/V-/ID/NTC） |
| 12 | 状态指示 | 3× LED (R/G/B) | 显示 RX 工作状态 |
| 13 | 磁吸对准 | 4× N52 磁铁 (Φ8×3mm) | 与 TX 充电座物理对准 |

## 模块详解

### 模块 1：RX 谐振

```
磁场 ──► [PCB 螺旋线圈] ──► AC_OUT
              │
              └── [CBB 100nF] ── 接地（并联谐振）
```

- **核心元件**：PCB 内嵌线圈（与 TX 同规格）、CBB 100nF/100V 电容
- **设计要点**：线圈区域禁止铺地铜；与 TX 线圈镜像对称布局

### 模块 2：整流滤波

```
AC_OUT ──► [MB6S 整流桥] ──► DC_BUS
                │
                └── [L_filter 10μH] + [C_filter 220μF] ── GND
```

- **核心元件**：MB6S（4 个肖特基二极管集成）、滤波电感 10μH、滤波电容 220μF
- **设计要点**：MB6S 靠近 RX 线圈；π 形滤波在整流后

### 模块 3：RX 控制核心

```
DC_BUS ──► BQ51013B ──► VOUT_5V
              │
              ├── VCC（5V 供电）
              ├── GND
              ├── OUT（5V 输出）
              ├── AD（通信解调）
              └── CHG / PG（状态指示）
```

- **核心元件**：**BQ51013B**（5W Qi RX 单芯片方案）
- **设计要点**：去耦电容靠近 IC 引脚；OUT 引脚加滤波电容

### 模块 4：电源管理（LDO）

```
VOUT_5V ──► [AMS1117-3.3] ──► VCC_3V3
                 │
                 ├── C_in (1μF)
                 └── C_out (1μF)
```

- **核心元件**：AMS1117-3.3 LDO 稳压器
- **设计要点**：输入输出电容必须紧贴 IC

### 模块 5：MCU 控制（核心创新点）

```
STM32G030F6P6
   │
   ├── VDD/VSS（3.3V 供电 + 地）
   ├── PA0 (ADC)     → ID 检测输入
   ├── PB0 (GPIO)    → PROG 切换控制
   ├── PB1 (PWM)     → LED 状态指示
   ├── PB6/PB7 (I2C) → 可选 OLED 显示屏
   └── NRST          → 复位电路
```

- **核心元件**：**STM32G030F6P6**（Cortex-M0+，TSSOP-20）
- **设计要点**：去耦电容；晶振（如使用外部晶振）；SWD 调试接口预留

### 模块 6：ID 检测

```
VCC_3V3 ──┬── [R_pull 10kΩ] ──┬── PA0 (ADC)
          │                       │
          │                    XH2.54 Pin3 (ID)
          │                       │
          │                  [R_id 10kΩ 或 20kΩ]
          │                       │
         GND                     GND
```

- **核心元件**：10kΩ 上拉电阻（板载）+ ID 识别电阻（电池内置）
- **设计要点**：上拉电阻靠近 MCU 引脚；走线避开高频信号

### 模块 7：PROG 切换

```
   STM32 PB0 ──┬── Q1 (AO3400) Gate
              │        │
              │        └── R1 (3kΩ) ── CN3058E PROG
              │
              └── Q2 (AO3400) Gate
                       │
                       └── R2 (1kΩ) ── CN3058E PROG

（Q1/Q2 漏极接 PROG，源极接各自 R1/R2）
```

- **核心元件**：2× AO3400（N-MOSFET，低导通电阻）+ 2× R_PROG（3kΩ/1kΩ）
- **设计要点**：PROG 节点走线短；R_PROG 精度 1%

### 模块 8：充电管理（核心）

```
BQ51013B 5V 输出 ──► [CN3058E VIN]
                         │
                         ├── PROG ← 接模块 7（PROG 切换）
                         ├── BAT ────► 模块 9（保护板）
                         ├── STAT ───► LED 充电指示
                         ├── CE ──────► MCU 控制（使能）
                         └── TEMP ───► 模块 10（NTC）
```

- **核心元件**：**CN3058E**（双化学兼容充电管理 IC）
- **设计要点**：VIN 加去耦电容（10μF）；BAT 加 10μF 输出电容

### 模块 9：电池保护

```
CN3058E BAT ──┬── [8205A 双 MOS] ──┬── XH2.54 V+
              │                       │
              │   ┌──────────┐        │
              └───┤ DW01A    ├────────┘
                  │ 保护 IC   │
                  └──────────┘
                      │  V-
                      └── XH2.54 V-
```

- **核心元件**：DW01A（保护 IC）+ 8205A（双 N-MOSFET）
- **设计要点**：DW01A 检测脚走线短；8205A 散热焊盘加大

### 模块 10：NTC 温度监测

```
CN3058E TEMP ──┬── XH2.54 Pin4 (NTC)
               │
               └── 10kΩ NTC 热敏电阻（电池内置）── GND
```

- **核心元件**：10kΩ NTC（B=3950，热敏电阻）
- **设计要点**：NTC 装在电池仓内侧，贴近电池表面

### 模块 11：电池接口

```
XH2.54-4P（直插/贴片）
   │
   ├── Pin1: V+ ── 电池正极
   ├── Pin2: V- ── 电池负极 + GND
   ├── Pin3: ID ── 模块 6
   └── Pin4: NTC ── 模块 10
```

- **核心元件**：XH2.54-4P 连接器
- **设计要点**：连接器放在板边便于电池线束插拔

### 模块 12：状态指示

```
STM32 PB1 (PWM) ──► [R 1kΩ] ──► [LED_RGB] ──► GND
```

- **核心元件**：3× 0603 LED（R/G/B）+ 3× 1kΩ 限流电阻
- **设计要点**：LED 放仓体透明观察窗位置

### 模块 13：磁吸对准（机械）

- **核心元件**：4× N52 圆柱磁铁（Φ8×3mm）
- **布置**：环形对称，与 TX 镜像
- **设计要点**：磁铁孔避开走线和高频元件

## 模块布局建议（PCB Layout）

```
┌──────────────────────────────────┐
│  [1 RX 线圈区]（与 TX 镜像）         │
│  4× [13 磁铁孔]                     │
│                                  │
│  [2 整流桥]   [3 BQ51013B]  [4 LDO]│
│                                  │
│  [5 MCU]   [6 ID 检测]   [12 LED]  │
│                                  │
│  [7 PROG 切换]   [8 CN3058E]        │
│                                  │
│  [9 保护板]   [10 NTC]   [11 XH2.54]│
└──────────────────────────────────┘
```

**布局原则**：
- 线圈区放板中央，与磁铁孔同心
- 控制电路（MCU/ID/LED）放板边，避开高频
- 充电和保护部分靠近电池接口（XH2.54）
- 整体尺寸目标：50×50mm（4 层板）
