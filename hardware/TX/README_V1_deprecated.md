## 模块清单（7 个）

| # | 模块 | 核心元件 | 作用 |
|---|---|---|---|
| 1 | 电源输入 | USB-C母座 + TVS + PPTC | 接入 5V/9V 适配器 + 浪涌/过流保护 |
| 2 | DC-DC 降压 | MP1584EN + L/C 滤波 | 5V/9V → 5V/3.3V，给控制电路供电 |
| 3 | TX 控制核心 | **BQ500100** | Qi 协议握手、PWM 生成、FOD 检测 |
| 4 | 半桥驱动 | IR2104 + 自举电容 | 放大 PWM 信号驱动 MOSFET |
| 5 | 功率开关 | 2× AO3400 (N-MOS) | 半桥逆变，输出 150 kHz 交流方波 |
| 6 | LC 谐振 | PCB 线圈 + CBB 100nF | 谐振升压，产生强磁场 |
| 7 | 状态指示 | 3× LED (R/G/B) | 显示 TX 工作状态 |
| 8 | 磁吸对准 | 4× N52 磁铁 (Φ8×3mm) | 与 RX 仓物理对准 |

## 模块详解

### 模块 1：电源输入

```
[V_BUS] ──┬── [TVS SMBJ5.0A] ──┬── [PPTC 0.5A] ──┬── VBUS_5V
           │                      │                       │
          GND                    GND                     GND
```

- **核心元件**：USB-C母座、SMBJ5.0A TVS、PPTC 自恢复保险丝
- **设计要点**：TVS 紧贴 USB-C 母座，PPTC 在 TVS 之后

### 模块 2：DC-DC 降压

```
VBUS_5V ──► [  ] ──► VOUT_5V
                │
                ├── L1 (4.7μH)
                ├── C_in (22μF)
                └── C_out (22μF)
```

- **核心元件**：MP1584EN（开关电源芯片）、4.7μH 电感、22μF 输入输出电容
- **设计要点**：输入/输出电容靠近 IC 引脚，电感远离敏感信号### 模块 3：TX 控制核心

```
BQ500100（TI 5W Qi TX 控制器）
   │
   ├── VCC（5V 供电）
   ├── GND
   ├── BOOT（自举电容）
   ├── PWM_H / PWM_L（半桥驱动输出）
   ├── I_SENSE（电流采样）
   ├── COMM（通信解调输入）
   └── FOD_TEST（异物检测）
```

- **核心元件**：**BQ500100**（嘉立创开源参考设计的主角）
- **设计要点**：去耦电容多颗并联（100nF + 10μF）；地线铺铜完整

### 模块 4：半桥驱动

```
BQ500100 ──► [IR2104] ──┬── Q1 Gate（高边）
                       └── Q2 Gate（低边）
                       │
                       └── 自举电容 C_boot + D_boot
```

- **核心元件**：IR2104（半桥驱动器）、自举电容（100nF）、自举二极管（1N4148）
- **设计要点**：自举电路靠近 IR2104 高边驱动引脚

### 模块 5：功率开关（半桥）

```
V+ (12V) ──┬── Q1 (AO3400) ──┬── 线圈一端
           │                    │
           │                    │
GND  ──────┴── Q2 (AO3400) ──┴── 线圈另一端
```

- **核心元件**：2× AO3400（N-MOSFET）
- **设计要点**：Q1/Q2 紧靠线圈放置，走线短而宽，散热焊盘加大

### 模块 6：LC 谐振

```
线圈一端 ──► [PCB 螺旋线圈] ──► 线圈另一端
                  │
                  └── [CBB 100nF] ── 接地
```

- **核心元件**：PCB 内嵌线圈（顶层+底层并联，12 匝）、CBB 100nF/100V 电容
- **设计要点**：线圈区域禁止铺地铜；线圈下面走线避开

### 模块 7：状态指示

```
BQ500100 STAT ──► [R 1kΩ] ──► [LED_R] ──► GND
BQ500100 STAT ──► [R 1kΩ] ──► [LED_G] ──► GND
BQ500500100 STAT ──► [R 1kΩ] ──► [LED_B] ──► GND
```

- **核心元件**：3× 0603 LED（R/G/B）+ 3× 1kΩ 限流电阻
- **设计要点**：LED 放板边便于观察

### 模块 8：磁吸对准（机械）

- **核心元件**：4× N52 圆柱磁铁（Φ8×3mm）
- **布置**：环形对称，4颗绕线圈外圈，极性交替
- **设计要点**：磁铁孔位预先留出，PCB 上做安装沉孔或卡扣

## 模块布局建议（PCB Layout）

```
┌──────────────────────────────────┐
│  [1 USB-C]    [2 DC-DC]    [3 BQ500100]│
│                                  │
│  [4 半桥 IR2104]    [5 MOSFET×2]      │
│                                  │
│  ┌─────────────────────────┐   │
│  │  [6 PCB 线圈区]            │   │
│  │  (内嵌)                  │   │
│  └─────────────────────────┘   │
│  4× [8 磁铁孔] 围线圈布置        │
│                                  │
│  [7 LED×3]                      │
└──────────────────────────────────┘
```

**布局原则**：
- 高频信号（半桥、线圈）远离控制信号
- 强电（V+/GND）走粗线或铺铜
- 磁铁孔放在板边，不影响内部走线
- 整体尺寸目标：50×60mm（4 层板）
