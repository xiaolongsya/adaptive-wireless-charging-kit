# 发射端 (TX) 硬件设计 - 最终版 V3.0

本目录包含无线充电发射端的原理图、PCB 设计及物料清单。

**注意：之前的 V1.0 (BQ500100) 分立方案已被归档为废案，请勿再参考 `README_V1_deprecated.md` 中的过时参数。**

## 1. 核心芯片选型：IP6805U (英集芯)
为了解决 QFN 封装难以纯手工焊接的痛点，本项目最终选用了 **IP6805U (eSOP-8 封装)** 作为发射端大脑。
*   **极简封装**：仅 8 个引脚，间距高达 1.27mm，对新手电烙铁极其友好。
*   **全集成方案**：内置全桥功率 MOS，外部元器件相比旧方案进一步减少（去除了外部 NTC 和 VCC 降压电阻）。

> 💡 **手工焊接腹部大焊盘技巧**：
> IP6805U 底部带有一块用于散热的 EPAD。为了用电烙铁焊接它，请在 PCB Layout 时，在芯片腹部正中央放置一个内径 `1.5mm` 的大过孔 (Via)。焊接时先焊好两侧的 8 个引脚，然后把板子翻转，将焊锡丝塞入背面的大过孔中加热，让锡水流入腹部缝隙即可完美固定并散热。

## 3. 关键布线 (Layout) 指南
1. **电流回路分离**：全板必须区分 **模拟地 (GND)** 和 **功率地 (PGND)**。主供电滤波电容 (CP1/CP2) 和芯片的 EPAD 必须接功率地。它们之间通过 R5 (20mΩ) 唯一桥接。
2. **大电流走线**：从 `LX1` 到谐振电容、线圈，再回流到 `LX2` 的线路，流淌着高达 2A 的交流电。在布线时必须尽可能粗，且尽量短。
3. **敏感走线**：检波网络（特别是 `V_DECODE` 相关走线）较为敏感，应远离线圈的大功率交流区域。
