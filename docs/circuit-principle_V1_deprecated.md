# 电路原理完整讲解

> 本文档从 USB-C 插上电源的那一刻开始，逐步追踪电流、信号、控制指令的完整流向，
> 让你能在答辩时从头到尾讲清楚每一焦耳电能的来去。

---

## 〇. 一句话原理

> TX 把 5V/9V 直流电**调制成 100-205 kHz 高频交变磁场**，RX 端的线圈在磁场中感应出交流电压，
> 整流滤波后给电池充电。磁铁保证线圈对准，MCU 识别电池类型后智能切换充电电流。

---

## 一、宏观视角：能量如何从墙插走到电池

```
┌────────┐    USB-C    ┌──────────────────┐  100-205 kHz  ┌──────────────────┐  XH2.54  ┌─────────┐
│ 墙插    │  5V/9V DC  │    TX 充电座      │  磁场穿过     │    RX 电池仓      │   4-pin   │  电池    │
│ 适配器  │ ─────────► │ (DC→AC→磁场)     │  空气间隙     │ (磁场→AC→DC)     │ ────────► │ 14500/  │
│        │            │                  │                  │                  │           │ 18650   │
└────────┘            └──────────────────┘                  └──────────────────┘           └─────────┘
```

四个阶段：**整流降压 → 高频逆变 → 磁耦合 → 整流充电**

## 三、TX 端原理（直流 → 磁场）

### 3.1 USB-C 输入与保护电路

```
USB-C 适配器                              TX 板入口
   │                                          │
   ▼                                          │
┌──────┐                                   ┌──────────┐
│ VBUS │ ────► [TVS SMBJ5.0A] ──► [PPTC] ─►│ 母座 +TVS │
│ 5/9V │        钳位瞬态过压     自恢复     └──────────┘
└──────┘        （防浪涌）      （防过流）
```

**两个保护元件的作用**：

| 元件 | 保护对象 | 工作原理 |
|---|---|---|
| **TVS（SMBJ5.0A）** | 防瞬态过压 | 电压超过 5V 钳位，把浪涌电流导入地 |
| **PPTC（自恢复保险丝）** | 防持续过流 | 电流过大时电阻急剧升高，断路；冷却后恢复 |

> 即使墙插短路或插错电源，也不会烧后级电路。

### 3.2 DC-DC 降压（MP1584）

```
USB-C 5V/9V ──► MP1584（开关电源芯片）──► 5V/3.3V 母线
                  │
                  ├─ 5V 给 BQ500100 供电
                  └─ 3.3V 给 MCU/LED 供电（经 LDO）
```

**为什么需要降压？**
- BQ500100 工作电压 5V，USB-C 5V 直供看似可行，但若用 9V PD 必须降压
- MP1584 是 3A 降压芯片，输入最高 28V，输出可调

**开关电源 vs 线性电源**：
- 5W 输出，开关电源效率 90%+，线性只有 50-60%
- 选 MP1584 而不是 7805，避免发热

### 3.3 BQ500100 TX 控制器（核心大脑）

```
BQ500100 内部框图（简化）：
                                    ┌─────────────┐
   USB 5V ──────────────────────────►│ 电源管理     │
                                    └─────────────┘
                                    ┌─────────────┐
   线圈电流采样 ────────────────────►│ ADC 监测     │──► 数字控制核心
                                    └─────────────┘           │
                                    ┌─────────────┐           ▼
   通信 ASK 解调 ◄──────────────────┤ 通信模块     │   ┌──────────┐
                                    └─────────────┘   │ PWM 生成  │
                                                      └─────┬────┘
                                                            │
                                                            ▼
                                                   驱动信号 → 半桥
```

**BQ500100 内部做四件事**：

1. **产生 PWM**：输出 100-205 kHz 的两路相位相反 PWM（典型 150 kHz）
2. **通信解调**：监听 RX 端通过负载调制回传的 ASK 信号（数据包）
3. **功率调节**：根据 RX 反馈的"需要多少功率"动态调整 PWM 占空比
4. **FOD 异物检测**：监测线圈电流异常，识别金属异物

### 3.4 半桥驱动电路（IR2104 + 2× MOSFET）

```
BQ500100 ──► IR2104（半桥驱动器）
                 │
                 ├──► 高边 MOSFET Q1（AO3400）
                 │       │
                 │       ├── Source ──┐
                 │       │            │
                 │       │            ▼
                 │       │        线圈一端
                 │       │            │
                 │       ├── Drain ──┤ ── 12V
                 │
                 ├──► 低边 MOSFET Q2（AO3400）
                 │       │
                 │       ├── Source ── GND
                 │       ├── Drain ───┘ (接到线圈另一端)
                 │
                 └── 自举电容（C_BOOT）
```

**为什么需要半桥而不是直接输出？**
- BQ500100 输出的 PWM 信号驱动能力很弱（mA 级）
- 需要 IR2104 这样的驱动器把它放大到能驱动 MOSFET 的级别（A 级）
- 高边 MOSFET 需要"自举电路"才能驱动（因为 Source 电压在浮动）

**半桥工作原理**（一个开关周期）：
```
t=0:    Q1 OFF, Q2 ON  → 线圈电流向下流（A→B）
t=Δt:    Q1 ON,  Q2 OFF → 线圈电流向上流（B→A）
如此反复 → 产生高频交流方波
```

### 3.5 LC 谐振网络（关键的能量转换单元）

```
   Q1 漏极
      │
      ├─── C_RES（谐振电容，0.1μF/100V CBB）
      │       │
      │       │
      ▼       ▼
   ┌─────────────┐
   │  TX 线圈 L  │  （A11 标准线圈，电感 ~6-10μH）
   │  ~6-10μH    │
   └─────────────┘
      │
      └───── Q2 漏极
```

**谐振原理**：线圈 L 和电容 C_RES 组成 LC 振荡电路，谐振频率：

```
        1
f = ─────────
    2π√(LC)
```

如果 L=10μH, C=0.1μF：
```
f = 1/(2π × √(10×10⁻⁶ × 0.1×10⁻⁶))
  = 1/(2π × √(10⁻¹²))
  = 1/(2π × 10⁻⁶)
  ≈ 159 kHz ✓（落在 Qi 协议 100-205 kHz 范围）
```

**为什么要谐振？**
- 线圈本身阻抗低，直流通电只发热不辐射
- 在谐振频率下，LC 回路阻抗高，电流小、电压高 → 强磁场辐射
- Q 值（品质因数）越高，磁场强度越大、传输距离越远

### 3.6 磁吸对准结构（4 颗 N52 磁铁）

```
俯视图（从 TX 侧看下去）：

        N52 磁铁（4 颗环形布置）
       ┌─────────────────────┐
       │   ●          ●      │
       │     TX 线圈       │
       │   ●          ●      │
       └─────────────────────┘
                ▲
                │ 磁吸吸力
                ▼
        RX 侧磁铁（极性相反）
```

**为什么是4颗而不是1颗？**
- 1颗磁铁：吸力集中但容易侧翻
- 4颗环形：自动对准中心（"花瓣效应"）+ 吸力均匀 + 防滑

**N52 磁铁选型**：剩磁 ≥ 1.2 T，是磁吸应用性价比最高的等级。

## 四、RX 端原理（磁场 → 直流）

### 4.1 线圈感应 + 整流滤波

```
RX 线圈 L2（与 TX 线圈同规格 A11）
   │  感应出 AC 电压（5-10V@150 kHz）
   │  [感应电压幅值取决于距离/对准]
   ▼
C_RES2（与 L2 谐振）
   │  提升拾取效率（同频谐振）
   ▼
整流桥（MB6S，4 个肖特基二极管）
   │  AC → DC（全波整流）
   │  [肖特基压降 0.3V，普通硅 0.7V，效率高 8%]
   ▼
π 形滤波（L_filter + C_filter）
   │  平滑直流，抑制纹波
   ▼
DC_BUS（约 5-7V 直流）
```

**整流桥工作原理**（4 个二极管组成）：

```
     ┌─D1─┐    ┌─D2─┐
     │    ▼    │    ▼
AC1 ─┤    ├─ DC+ ├    ├─ AC2
     │    ▲    │    ▲
     └─D3─┘    └─D4─┘
          │
          DC-
```

正半周：D1、D3 导通 → DC+ 流入电流
负半周：D2、D4 导通 → DC+ 流入电流
结果：DC+/DC- 间得到脉动直流

### 4.2 BQ51013B RX 控制器

```
DC_BUS 5-7V ──► BQ51013B
                    │
                    ├─ 内部同步整流（比 MB6S 更高效，可选旁路）
                    ├─ LDO 输出 5V 稳定（VOUT 引脚）
                    ├─ 通信调制：负载调制产生 ASK 信号回传给 TX
                    └─ 状态输出：CHG / PG 引脚
                              │
                              ▼
                          5V/1.5A 输出
                          （可调，实际给 ~1A）
```

**BQ51013B 比 MB6S 整流桥多了什么？**

| 功能 | MB6S（被动） | BQ51013B（主动） |
|---|---|---|
| 整流 | 4 个二极管（0.3V×2 损耗） | 同步整流（0.05V 损耗） |
| 通信 | 无法通信 | ✅ 负载调制 ASK |
| 电压调节 | 无 | ✅ LDO 输出稳定 |
| FOD | 无 | ✅ 配合 TX 实现 FOD |

> **关键**：BQ51013B 通过 ASK 通信告诉 TX "我需要多少功率"，TX 据此调整 PWM 占空比。这就是 Qi 协议的核心。

### 4.3 STM32G030 MCU 控制（核心创新点）

```
                ┌─────────────────────────────┐
                │       STM32G030F6P6          │
                │         (Cortex-M0+)         │
                └─────────────────────────────┘
                       │  │  │
        ┌──────────────┘  │  └──────────────┐
        │                 │                 │
        ▼                 ▼                 ▼
   PA0 (ADC)         PB0 (GPIO)         PB1 (PWM/LED)
   ID 检测           PROG 切换          状态指示
```

**MCU 干的 3 件事**：

#### ① ID 检测（ADC）
```
   VCC (3.3V)
      │
      ├──[R_pull = 10kΩ]─────┬───── PA0 (ADC)
      │                       │
   XH2.54 Pin3                │
   (ID 脚)                    │
      │                       │
      ├──[R_id 电池内置]──────┘
      │   10kΩ → 14500
      │   20kΩ → 18650
      │   悬空  → 无电池
      │
     GND
```

**ADC 读数公式**：
```
V_ADC = 3.3V × R_id / (R_pull + R_id)

R_id=10kΩ: V_ADC = 3.3 × 10/20 = 1.65V → ADC=2048（约 0.6×VCC）
R_id=20kΩ: V_ADC = 3.3 × 20/30 = 2.20V → ADC=2730（约 0.83×VCC）
悬空:        V_ADC = 3.3V       → ADC=4095（约 1.0×VCC，识别为"无电池"）
```

#### ② PROG 切换（GPIO + MOSFET）
```
        ┌─ 14500 充电电流档 (R1=3kΩ → 400mA)
        │   AO3400 Q1 ← PB0 控制
        ▼
   CN3058E PROG 引脚 ── 切换节点 ──┐
   ▲                                    │
   │                                    │
        ┌─ 18650 充电电流档 (R2=1kΩ → 1200mA)
        │
   AO3400 Q2 ← PB0 控制（同相/反相）
```

**PROG 引脚电流公式**（CN3058E）：
```
I_charge = 1200 / R_PROG (kΩ) mA

R1=3kΩ:  I = 400 mA ✓ 14500 用（800mAh × 0.5C）
R2=1kΩ:  I = 1200 mA ✓ 18650 用（2500mAh × 0.5C）
```

#### ③ LED 状态指示
```
PB1 (PWM) ──► LED_R/G/B ──► GND

- 上电无电池：红色闪烁（1Hz）
- 检测到 14500：绿色常亮（400mA 充电中）
- 检测到 18650：蓝色常亮（1200mA 充电中）
- 充满：紫色呼吸灯（PWM 调光）
- 错误（过温/短路）：红色快闪（4Hz）
```

### 4.4 CN3058E 充电管理 IC

```
BQ51013B 5V 输出 ──► CN3058E VIN
                          │
                          ├─ PROG（外接 R1/R2 切换）
                          ├─ BAT ──────► 电池正极（经 DW01A）
                          ├─ STAT ─────► LED 状态指示
                          ├─ CE ────────► MCU 控制（使能）
                          └─ TEMP ──────► NTC 10kΩ
```

**CN3058E 三段充电流程**：
```
Vbat
 ↑
 │     ┌──── 4.2V（CV 阶段）
 │    ╱
 │   ╱  CC 阶段（恒流）
 │  ╱
 │ ╱
 │╱  预充电（涓流，<3.0V 启动）
 └────────────────────────────► 时间

阶段1：预充电（电池<3.0V）  I=0.1×I_charge  修复过放电池
阶段2：恒流充电            I=I_charge       主充阶段
阶段3：恒压充电            V=4.2V           I 逐渐下降
终止：电流降至 I/10        进入待机
```

### 4.5 电池保护（DW01A + 8205A）

```
BAT+ ──┬──[8205A 双 MOS]──┬── 电池正极
        │                  │
        │   ┌──────────┐   │
        └───┤ DW01A    ├───┘
            │ 保护 IC   │
            └──────────┘
                │  V- (监测)
                └── 电池负极
```

**4 重保护**：
| 保护类型 | 触发条件 | 动作 |
|---|---|---|
| 过充保护 | Vbat > 4.3V | 切断充电 MOS |
| 过放保护 | Vbat < 2.5V | 切断放电 MOS |
| 过流保护 | I > 3A | 切断放电 MOS |
| 短路保护 | I > 6A（瞬态） | 切断放电 MOS |

### 4.6 XH2.54-4P 接口

```
引脚定义（从仓体外侧看进去）：
┌─────┐
│1 V+ │ ── 电池正极
│2 V- │ ── 电池负极
│3 ID │ ── 接识别电阻到 GND（10k/20k/悬空）
│4 NTC│ ── 接 10kΩ NTC 到 GND（温度监测）
└─────┘
```

## 五、TX-RX 通信（Qi 协议核心）

### 5.1 握手过程（从 TX 上电到稳定充电）

```
时序图：

TX 上电 ──┬── 等待 RX 放置
          │
          ├─[1] Ping 阶段：发送短脉冲探测（间隔 500ms）
          │       │ 检测到 RX 谐振 → 进入 Identification
          │
          ├─[2] Identification：RX 上电，发送"我是 Qi 设备"
          │       │ 等待 RX 回应 ACK
          │
          ├─[3] Configuration：协商最大功率（5W）
          │       │
          ▼
       [5] Power Transfer：开始全功率传输
          │
          ├─ RX 持续监测整流电压/电流
          ├─ 通过负载调制回传"给我多一点/少一点"
          ├─ TX 实时调整 PWM 占空比
          │
          ▼
       稳定充电（直到 RX 报告充满或断开）
```

### 5.2 ASK 通信原理

**RX 发送数据**：
```
RX 端：通过切换内部负载电阻，瞬时改变 TX 线圈电流
       负载加大 → 线圈电流增大 → TX 检测到
       负载减小 → 线圈电流减小 → TX 检测到
       这种"幅度变化"就是 ASK（Amplitude Shift Keying）
```

**TX 解码**：
```
BQ510100 监测半桥电流 ADC
   │
   ├─ 检测到电流变化模式 → 解码为 0/1 bit
   ├─ 累积成字节（Qi 协议帧）
   └─ 调整 PWM 占空比
```

## 六、双电池识别工作流程（端到端）

```
电池插入 RX 仓
    │
    ▼
上电瞬间
    │
    ├─[1] MCU 启动，ADC 初始化
    │
    ├─[2] 延时 100ms（等电源稳定）
    │
    ├─[3] 读取 ID 引脚电压
    │   ├─ 1.65V ± 0.2V → 14500 识别码
    │   ├─ 2.20V ± 0.2V → 18650 识别码
    │   └─ >2.8V      → 无电池 / 错误
    │
    ├─[4] 设置 PROG 电阻
    │   ├─ 14500 → Q1 ON（接 R1=3kΩ）→ 400mA
    │   └─ 18650 → Q2 ON（接 R2=1kΩ）→ 1200mA
    │
    ├─[5] 点亮对应 LED
    │   ├─ 14500 → 绿色常亮
    │   └─ 18650 → 蓝色常亮
    │
    ├─[6] 持续监测
    │   ├─ ID 变化（电池被换）→ 重新执行 [4][5]
    │   ├─ NTC > 60°C → 关闭 PROG 输出，红色快闪
    │   ├─ 电流降至 I/10 → 充电完成，紫色呼吸
    │   └─ 电池拔除 → 关闭输出，待机
```

## 七、保护机制全图

```
┌──────────────────────────────────────────────────────────┐
│                    6 重保护体系                            │
└──────────────────────────────────────────────────────────┘

1. USB-C 入口
   ├─ TVS 防浪涌     ← 防止插拔电弧损坏
   └─ PPTC 防过流    ← 防止短路烧板

2. DC-DC 输入
   └─ 输入欠压锁定   ← 输入低于阈值拒绝工作

3. TX 端
   ├─ BQ500100 FOD  ← 异物检测（金属不充电）
   ├─ 过温关断      ← 线圈/驱动温度 > 阈值
   └─ 过流关断      ← 母线电流异常

4. RX 整流后
   ├─ BQ51013B OVP  ← 整流输出过压保护
   └─ BQ51013B OCP  ← 输出过流保护

5. CN3058E 充电
   ├─ 输入欠压锁定
   ├─ NTC 温度监测  ← 电池过温停充
   └─ 充电超时      ← 长时间未充满强制终止

6. DW01A 保护板
   ├─ 过充保护（>4.3V）
   ├─ 过放保护（<2.5V）
   ├─ 过流保护（>3A）
   └─ 短路保护（>6A）
```

## 八、关键参数计算

### 8.1 谐振电容选型

**目标**：f_res = 150 kHz

```
        1
C = ─────────
    (2πf)² × L

如果 L=10μH，f=150kHz：

C = 1 / ((2π × 150000)² × 10×10⁻⁶)
  = 1 / (8.88×10¹¹ × 10⁻⁵)
  ≈ 113 nF

→ 选 100nF / 120nF CBB 电容（实际微调到谐振峰值）
```

### 8.2 ID 电阻分压计算

| R_id | V_ADC | ADC 值 (12-bit) | 识别 |
|---|---|---|---|
| 10kΩ | 1.65V | 2048 | 14500 |
| 20kΩ | 2.20V | 2730 | 18650 |
| 悬空 | 3.30V | 4095 | 无电池 |
| 5kΩ | 1.10V | 1365 | 异常/错误 |

### 8.3 充电电流计算

**CN3058E PROG 公式**：
```
I_charge (mA) = 1200 / R_PROG (kΩ)

目标电流：
- 14500 (800mAh) × 0.5C = 400mA → R1 = 1200/400 = 3.0kΩ → 用 3.0kΩ
- 18650 (2500mAh) × 0.5C = 1250mA → R2 = 1200/1250 = 0.96kΩ → 用 1.0kΩ
```

### 8.4 功率链路估算

```
输入：USB-C 5V/2A = 10W
   ↓ DC-DC 效率 90%
5V/1.8A = 9W
   ↓ BQ500100 + 半桥效率 85%
谐振输出 ≈ 7.6W
   ↓ 磁耦合效率 60%（气隙 3mm）
RX 整流输入 ≈ 4.6W
   ↓ BQ51013B + CN3058E 效率 85%
到电池 ≈ 3.9W

→ 5W 输入时，实际充电功率约 2-3W
→ 14500（800mAh）充满时间 ≈ 1.5 小时
→ 18650（2500mAh）充满时间 ≈ 4 小时
```

## 九、常见问题排查指南

| 故障现象 | 可能原因 | 排查方向 |
|---|---|---|
| TX 通电无反应 | USB-C 母座 / TVS 短路 | 测 VBUS 是否 5V |
| TX 上电指示灯不亮 | 5V 母线故障 | 测 MP1584 输出 |
| TX 找不到 RX | BQ500100 没起振 | 检查半桥驱动信号 |
| RX 完全无输出 | 线圈没对准 / 距离太远 | 确认磁吸贴合 |
| RX 有输出但 MCU 不工作 | 3.3V LDO 没起 / MCU 晶振 | 测 VCC、晶振波形 |
| ADC 识别错误 | R_pull / R_id 配错 | 用万用表量 ID 电压 |
| 充电电流不对 | PROG 电阻档位错 | 测 PROG 引脚电压 |
| 电池充不进去 | DW01A 保护未解除 | 检查 Vbat 是否 > 3V |
