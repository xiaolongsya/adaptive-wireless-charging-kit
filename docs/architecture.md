# Adaptive Wireless Sealed Battery Charging Kit - Architecture V3.0 (FINAL)

## 1. 架构演进与废案说明

在项目的开发过程中，发射端 (TX) 架构经历了三次重大迭代。为了保留开发过程的历史记录，旧版本的文档已被备份并标记为废案（Deprecated）。

*   **V1.0 废案 (BQ500100 + IR2104 分立方案)**: 
    *   **历史文档**: `docs/circuit-principle_V1_deprecated.md`, `hardware/TX/README_V1_deprecated.md`
    *   **废弃原因**: 采用德州仪器 (TI) 的 BQ500100 搭配外部 MOS 驱动器与全桥功率管，电路过于复杂，外围元件庞大，BOM 成本高，完全不符合本项目“极简、高可靠”的理念。
*   **V2.0 废案 (IP6806 QFN32 方案)**:
    *   **历史文档**: `docs/architecture_V2_deprecated.md`
    *   **废弃原因**: IP6806 是一颗优秀的 5W 全集成 SoC，大大简化了 V1.0 的电路。但由于其采用 **QFN-32 (0.5mm 间距，底部带散热焊盘)** 封装，对于比赛手工电烙铁焊接极度不友好，新手焊接成功率极低，容易出现虚焊和连锡死机。
*   **V3.0 最终决定版 (IP6805U eSOP-8 方案)**:
    *   **当前标准**: 本次全面转用英集芯 **IP6805U**。该芯片专为 5W 市场打造，采用对电烙铁极度友好的 **eSOP-8 (1.27mm 间距)** 封装。并且去掉了不必要的外部 NTC 和 VCC 降压电阻，在保证全集成高性能的同时，将外围 BOM 压缩到了极致。

## 2. 系统核心架构 (V3.0)

本项目旨在为全密封结构的电池包提供无线充电能力。系统主要分为两大部分：

1.  **无线发射端 (TX Board)**：采用 **Type-C (5V 输入)** + **IP6805U 高集成发射 SoC** + **A11 标准绕线线圈**。
2.  **无线接收与电池管理端 (RX Board)**：负责接收无线能量，并对密封电池进行安全、高效的充放电管理。

### 2.1 发射端 (TX) 硬件模块
*   **供电输入与保护**: 
    *   基于 Type-C 母座，集成 5.1k CC 下拉电阻以兼容 PD 充电头。
    *   增加 **SMBJ5.0A TVS 瞬态二极管**与 **2A 自恢复保险丝**，在插拔浪涌和异常短路时提供工业级保护。
    *   采用 **22uF (x2)** + 100nF 的 MLCC 电容矩阵，提供比官方参考设计更强劲的滤波能力。
*   **控制核心**: 
    *   **IP6805U (eSOP-8)**。内置全桥驱动、功率 MOS、ASK 通讯解调与异物检测 (FOD) 算法。
*   **谐振网络**: 
    *   4 颗 100nF (总计 400nF) 100V **C0G/NP0** 高频陶瓷电容并联，连接 A11 线圈，构成 5W 强力发射场。
*   **检波通讯**: 
    *   从 LX1 节点通过 1N5819 肖特基二极管提取微弱的 ASK 调制信号，分别送入 VDET 和 V_DECODE 引脚，实现与 RX 端的握手。
*   **手工焊接优化**:
    *   由于芯片采用 eSOP 封装，底部带有散热焊盘，PCB 设计时需在芯片腹部添加 1.5mm 内径大过孔。焊接时通过背面补锡的方式，完美解决电烙铁无法焊接底部焊盘的痛点。
