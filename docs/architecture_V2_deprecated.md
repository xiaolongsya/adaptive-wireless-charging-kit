> 文档版本：V2.0  
> 更新日期：2026-09-20  
> 适用对象：原理图设计、PCB Layout、固件开发、结构设计、系统测试与比赛答辩

## 0. 文档结论

本项目采用以下主架构：

- **输入电源**：USB Type-C，首版固定 5V/2A；
- **无线功率等级**：Qi BPP 5W；
- **使用场景**：设备静止时磁吸对准充电；
- **TX 端**：成熟 5W Qi 发射控制方案 + 标准 A11 绕线线圈 + 铁氧体片；
- **RX 端**：BQ51013B + 专用 RX 绕线线圈 + C1/C2 双谐振网络；
- **充电管理**：原生 4.2V 单节锂离子充电器，目标型号 BQ24040，备选 CN3065；
- **自适应控制**：STM32G030F6P6 根据电池 ID、温度和无线链路能力选择充电策略；
- **充电电流**：14500 使用 400mA，18650 使用 800mA；
- **保护策略**：输入保护、Qi FOD、RX 保护、硬件 NTC、充电管理、电芯保护和 MCU 软件保护共同构成多层安全体系；
- **机械结构**：非金属薄壁充电面、线圈背面铁氧体屏蔽、磁铁位于线圈有效区外缘；
- **首版原则**：优先保证链路可靠、安全和可测试，不采用自制 PCB 功率线圈，不追求极限功率。

### 0.1 旧版方案中已取消的内容

以下内容不得继续用于原理图设计：

1. **BQ500100 作为 Qi TX 控制器**：错误。BQ500100 是高侧电流检测放大器，不是发射控制器；
2. **IR2104 直接工作在 5V**：不可行，IR2104 驱动电源要求约 10～20V；
3. **RX 线圈后增加 MB6S，再接 BQ51013B**：错误，BQ51013B 已集成同步整流；
4. **CN3058E 直接实现 4.2V/1.25A 充电**：不采用，CN3058E 默认面向 3.6V LiFePO₄，且最大约 1A；
5. **TX/RX 使用相同的 12 匝 PCB 线圈**：首版取消；
6. **0.5A PPTC 支撑 5W 无线输出**：额定电流不足；
7. **USB-C 无 PD 控制器却声明支持 9V/12V**：首版取消；
8. **DW01A + 8205A 串联在电池正极**：取消，保护开关应按器件参考设计置于电池负极侧；
9. **在线圈附近直接增加铝箔散热**：禁止，可能产生涡流、发热和谐振偏移。

## 1. 项目目标与边界

### 1.1 项目目标

设计一套面向机器狗、密封仪器和便携式设备的磁吸无线充电系统，使设备在不暴露金属充电触点的情况下完成单节锂离子电池充电。

系统需要支持两类专用电池包：

| 电池类型 | 标称容量 | 满充电压 | 首版充电电流 | 识别方式 |
|---|---:|---:|---:|---|
| 14500 Li-ion | 约 800mAh | 4.2V | 400mA | 10kΩ ID 电阻 |
| 18650 Li-ion | 约 2500mAh | 4.2V | 800mA | 20kΩ ID 电阻 |

> 容量仅为项目默认值。实际电池包必须按照所选电芯数据手册确认允许充电电流。

### 1.2 首版设计边界

首版明确不实现：

- 运动中持续无线充电；
- 15W 或更高功率 Qi；
- USB PD 9V/12V 输入；
- 多节串联电池充电；
- 任意裸 14500/18650 电芯自动识别；
- Qi2 MPP 认证；
- 自研 Qi 通信协议栈；
- 首版 PCB 平面功率线圈；
- 量产级 IP67 认证。

### 1.3 “5W”的统一定义

本文中的 **5W** 指：

> 在良好对准条件下，Qi RX 端可获得最高约 5V/1A 的受控输出能力。

它不是指 USB 输入仅为 5W。考虑 TX、线圈耦合和 RX 损耗，USB 端应预留约 10W：

```text
USB 输入能力：5V × 2A = 10W
RX 最大输出：约 5V × 1A = 5W
电池端功率：约 1.2～3.4W，取决于电池电压和充电档位
```

## 3. TX 端架构

### 3.1 TX 模块划分

| # | 模块 | 主要功能 | 首版要求 |
|---|---|---|---|
| 1 | USB-C 输入 | 获取 5V 电源 | 5V/2A，暂不支持 PD |
| 2 | CC 检测 | 判断连接方向和源端电流能力 | 使用 Type-C Sink/CC 检测方案 |
| 3 | 输入保护 | ESD、过压、过流、软启动 | eFuse 优先，PPTC 为备选 |
| 4 | Qi TX 控制 | Ping、通信、功率控制、FOD | 采用成熟 5W 方案 |
| 5 | 功率桥 | 产生高频交流激励 | 完全按照 TX 参考设计 |
| 6 | TX 谐振 | 与 A11 线圈匹配 | 不自行套用固定 100nF |
| 7 | TX 线圈 | 产生交变磁场 | 标准绕线 A11 线圈 |
| 8 | 铁氧体屏蔽 | 导磁、降低后向泄漏和发热 | 覆盖完整线圈有效区 |
| 9 | 状态指示 | 待机、充电、完成、故障 | 由 TX 控制器状态脚驱动 |
| 10 | 磁吸定位 | 保持 TX/RX 同心 | 位于线圈外缘并留安全距离 |

### 3.2 TX 控制器选择原则

首版 TX 控制器必须满足：

- 5V 输入；
- Qi BPP 5W；
- 支持 A11 或等效线圈；
- 内置或参考实现 ASK 解调；
- 具有 FOD 或完整异物检测方案；
- 提供公开参考原理图和 PCB Layout；
- 器件可获得；
- 不要求项目团队从零实现 Qi 协议固件。

候选路线：

| 路线 | 优点 | 风险 | 推荐度 |
|---|---|---|---|
| 高集成国产 5W Qi TX SoC/模块 | 元件少、调试快、适合比赛 | 必须核实数据手册、库存和参考设计 | 首选 |
| BQ500211A EVM 架构 | TI 资料完整、A11 方案成熟 | 器件 NRND、全桥较复杂 | 原型备选 |
| BQ500511A + BQ50002A | Qi v1.2 参考资料完整 | 两芯片且 NRND | 原型备选 |
| MCU 自研 TX | 可控性高 | 固件、协议和 FOD 风险高 | 首版不采用 |

> BQ500100 只能在需要时作为电流检测器件使用，不能承担 TX 控制功能。

### 3.3 USB-C 输入链路

```text
USB-C 母座
   │
   ├─ CC1/CC2：Sink 识别与源端电流能力检测
   ├─ ESD：靠近接口布置
   └─ VBUS
        │
        ▼
      eFuse
        ├─ 过流限制
        ├─ 短路保护
        ├─ 软启动
        └─ 可选过压关断
        │
        ▼
      输入 π 滤波 / 大容量陶瓷电容
        │
        ▼
      TX 5V 功率母线
```

设计要求：

- 正常工作电流路径按至少 2A 设计；
- 不再使用 0.5A PPTC；
- 如果使用 PPTC，必须按密封外壳内最高温度进行降额；
- SMBJ5.0A 等器件仅用于 5V 母线，不允许在同一设计中直接输入 9V/12V；
- 首版使用指定的 5V/2A 或更高能力适配器；
- USB-C 仅提供电源，不连接 USB 2.0 数据线。

### 3.4 TX 工作逻辑

```text
TX 上电
  │
  ▼

  │
  ├─ 异常 → 关闭功率桥，故障指示

  ▼

  │
  ▼

  │
  ├─ 未检测到 RX → 返回 Standby
  │

  │
  ├─ 接收 RX 控制误差包
  ├─ 调整频率/占空比/母线功率

  ├─ 执行 FOD
```

## 4. 无线功率与磁性结构

### 4.1 线圈选型

首版采用标准绕线线圈，不使用 PCB 功率线圈。

TX 线圈要求：

- Qi A11 或与所选 TX 参考设计完全一致；
- 典型电感约 6～7µH，但最终以参考设计为准；
- 低直流电阻；
- 自带或匹配铁氧体片；
- 电流能力满足全桥谐振环流。

RX 线圈要求：

- 与 BQ51013B 推荐线圈尺寸和参数接近；
- 典型自由空间电感可位于约 10～15µH，但不得仅按标称值设计；
- DCR 足够低；
- 带完整铁氧体背板；
- 线圈尺寸与 TX 有效面积匹配。

### 4.2 RX 谐振网络

BQ51013B 的线圈应直接通过谐振网络连接 AC1/AC2：

```text
RX Coil ── C1（串联谐振）── AC1
   │                         │
   └──────── C2（并联）──────┘ AC2
```

实际连接以 BQ51013B 官方应用图为准，不允许在线圈和 AC1/AC2 之间增加外置整流桥。

参数计算：

\[
C_1=\frac{1}{(2\pi f_S)^2L'_S}
\]

\[
C_2=\frac{1}{(2\pi f_D)^2L_S-\frac{1}{C_1}}
\]

其中：

- \(L_S\)：RX 线圈自由空间电感；
- \(L'_S\)：在线圈、铁氧体、外壳、电池和 TX 测试夹具就位后的电感；
- \(f_S\)：约 100kHz；
- \(f_D\)：约 1MHz。

实施步骤：

1. 使用 LCR 表在 100kHz、约 1Vrms 条件下测量；
2. 先测 \(L_S\)；
3. 再按 TI 测试夹具或最终结构测 \(L'_S\)；
4. 先计算并选定 C1；
5. 使用 C1 的实际值计算 C2；
6. C1 使用多颗低损耗电容并联以降低 ESR；
7. C1/C2 耐压不低于 25V；
8. 在最终结构、磁铁和电池全部安装后重新测量与验证。

### 4.3 机械叠层

推荐叠层：

```text
TX 外侧
  │
  ├─ 防滑层，避开线圈中心或保持很薄
  ├─ 0.6～1.2mm 非金属充电面
  ├─ TX 绕线线圈
  ├─ TX 铁氧体片
  ├─ TX PCB / 功率器件
  └─ TX 底壳

             磁耦合间隙

RX 外侧
  │
  ├─ 0.6～1.2mm 非金属充电面
  ├─ RX 绕线线圈
  ├─ RX 铁氧体片
  ├─ RX PCB
  ├─ 隔热/绝缘结构
  └─ 电池
```

目标总有效距离：

- 优先：1.5～2.5mm；
- 可接受：不超过约 3mm；
- 超过 3mm 后必须重新测试满载能力和温升。

### 4.4 磁铁布局

磁铁只负责定位，不负责传输能量。

设计规则：

- 磁铁中心位于线圈外径之外或低磁通区域；
- 不形成连续金属环；
- 不在线圈之间增加钢片、螺钉或装饰金属；
- 采用机械限位保证磁吸后 TX/RX 线圈同心；
- 极性布置应具有防反装特性；
- 最终磁铁数量和吸力通过实物拉脱试验确定，不预先固定为 2～4kgf；
- 安装磁铁后重新测量线圈电感、效率、FOD 和温升；
- 磁铁与铁氧体之间保留足够距离，避免偏磁或局部饱和。

## 5. RX 电源链路

### 5.1 正确的 RX 能量流

```text
交变磁场
   │
   ▼
RX 线圈 + C1/C2
   │ 高频交流
   ▼
BQ51013B AC1 / AC2
   │
   ├─ 内部同步整流
   ├─ RECT 电压调节
   ├─ ASK 负载调制
   ├─ 过压/过流/过温保护
   └─ 5V 输出控制
   │
   ▼
VOUT_5V
   ├─► 3.3V LDO → STM32/LED/检测电路
   └─► 高侧开关 → 4.2V 锂电充电器 → 电池保护 → 电池
```

严禁使用以下链路：

```text
RX 线圈 → MB6S → LC 滤波 → BQ51013B
```

### 5.2 BQ51013B 外围要求

设计时至少包含：

- AC1/AC2 谐振网络；
- RECT 滤波电容；
- OUT 输出电容；
- ILIM 电阻；
- FOD 校准网络；
- 通信调制电容；
- EN1/EN2 合法默认电平；
- TS/CTRL 网络；
- CHG 状态输出；
- 暴露焊盘接地和热过孔；
- 参考设计规定的模拟地和功率地布局。

首版目标：

- VOUT：约 5V；
- 持续有效负载：至少 0.8A；
- 过流限制：按 5W 系统和官方设计流程设置，不追求 1.5A 输出；
- 完成充电后允许通过 TS/CTRL 或 EN 逻辑向 TX 发送结束功率传输请求，具体实现以原理图阶段验证为准。

## 6. 充电管理链路

### 6.1 充电芯片

首选：**BQ24040**。

选择原因：

- 原生支持单节 4.2V Li-ion/Li-polymer；
- 最大充电电流约 1A；
- 支持电池 NTC；
- 具备输入电压动态功率管理；
- 具备充电状态和电源状态输出；
- 更适合输出能力会随对准状态变化的无线电源。

备选：**CN3065**。

备选条件：

- 通过实测验证其输入源动态调节与 BQ51013B 配合稳定；
- 验证封装散热；
- 验证 400mA/800mA 电流切换；
- 验证状态输出和温度检测。

CN3058E 不作为 V2.0 首选器件。如因库存必须使用，应单独形成降级设计评审，不直接套用本文参数。

### 6.2 充电使能

充电器输入前增加由 MCU 控制的高侧负载开关：

```text
BQ51013B VOUT_5V
        │
        ├─► 3.3V LDO → MCU 始终先上电
        │
        └─► 高侧负载开关 → Charger VIN
                     ▲
                     │
              MCU CHARGER_EN
```

硬件默认状态：

- CHARGER_EN 使用下拉电阻；
- MCU 未启动、复位或失效时，充电器默认断电；
- 高侧开关应支持至少 1.5A，并具有反向电流阻断或确认不会形成不安全回灌。

### 6.3 两档充电电流

目标档位：

| 档位 | 用途 | 标称电流 |
|---|---|---:|
| LOW | 14500、安全启动、降额 | 400mA |
| HIGH | 18650 且链路稳定 | 800mA |

推荐电阻结构：

```text
ISET ── R_BASE ── GND             默认 400mA
  │
  └──── R_BOOST ── MOSFET ── GND  导通后等效 800mA
```

安全原则：

- MOSFET 关闭时必须为 400mA；
- GPIO 复位默认状态必须使 MOSFET 关闭；
- 从 400mA 切换到 800mA 前，先关闭充电器输入；
- 切换电阻后等待节点稳定，再重新使能充电器；
- 从 800mA 降到 400mA 同样执行“先停充、再切换、后恢复”；
- 电阻值按最终充电芯片数据手册计算，使用 1% 或更高精度器件。

### 6.4 功率与发热估算

线性充电器主要损耗近似为：

\[
P_D=(V_{IN}-V_{BAT})I_{CHG}
\]

典型情况：

| VIN | VBAT | 充电电流 | 充电器近似损耗 |
|---:|---:|---:|---:|
| 5.0V | 3.0V | 400mA | 0.8W |
| 5.0V | 3.7V | 400mA | 0.52W |
| 5.0V | 3.0V | 800mA | 1.6W |
| 5.0V | 3.7V | 800mA | 1.04W |
| 5.0V | 4.2V | 800mA | 0.64W |

因此：

- 充电 IC 必须使用暴露焊盘封装或充分散热铜皮；
- 焊盘下增加热过孔；
- 充电 IC 与电池 NTC 保持距离，避免芯片自身发热影响电池温度判断；
- MCU 根据电池温度和 VOUT 状态主动降流；
- 密封外壳完成后必须重新进行满载温升测试。

## 7. 电池包与保护架构

### 7.1 电池接口

首版采用 4Pin 电池接口：

| Pin | 名称 | 方向 | 说明 |
|---:|---|---|---|
| 1 | P+ | 充电器/负载 ↔ 电池包 | 受保护电池正极 |
| 2 | P- | 充电器/负载 ↔ 电池包 | 受保护电池负极、系统参考地 |
| 3 | ID | 电池包 → MCU | 电池类型识别电阻 |
| 4 | NTC | 电池包 → 充电器/MCU | 电池表面温度 |

电池包内部：

```text
14500 电池包：ID ── 10kΩ ── P-
18650 电池包：ID ── 20kΩ ── P-
NTC：10kΩ NTC ── P-
```

> ID 和 NTC 必须参考受保护端 P-，不得连接后绕过保护 MOSFET 的 B- 节点。

### 7.2 专用电池包原则

ID 电阻只能表示“电池包声明的类型”，不能验证实际电芯容量和化学体系。

因此：

- 仅允许专用电池托架或专用电池包接入；
- 14500/18650 托架应通过尺寸、插头或机械键位防止混装；
- 不允许用户用任意裸电芯加任意电阻冒充电池包；
- 每种电芯必须核对厂家允许充电电流；
- 若更换为 LiFePO₄，必须更换充电电压配置和 ID 编码，不能继续使用 4.2V 策略。

### 7.3 电芯保护选择

两种合法方案二选一：

#### 方案 A：使用带保护电池包——首版推荐

电池包内部已包含：

- 过充保护；
- 过放保护；
- 过流保护；
- 短路保护；
- NTC；
- ID 电阻。

RX 主板只连接 P+/P-/ID/NTC。

#### 方案 B：RX 主板实现保护

使用 DW01A 类保护器件时，按标准低侧结构连接：

```text
Cell B+ ───────────────────────── P+

Cell B- ── 8205A 背靠背 MOS ─── P-
             ▲
             │
           DW01A
```

充电器负极和外部负载负极必须连接 P-，不能直接连接 B-。

禁止在未验证的情况下将“带保护电池包”和“RX 板 DW01A”重复叠加。

## 8. MCU 控制架构

### 8.1 MCU 任务

STM32G030F6P6 负责：

1. 读取 ID 电阻并判断电池包类型；
2. 读取电池 NTC；
3. 监测 BQ51013B VOUT；
4. 监测电池电压 VBAT；
5. 控制充电器高侧开关；
6. 控制 400mA/800mA 档位；
7. 读取充电器 CHG/PG 状态；
8. 控制 RGB LED；
9. 记录故障原因；
10. 通过 SWD/UART 输出调试信息；
11. 可选驱动 OLED，但首版不作为必要功能。

### 8.2 建议引脚功能

最终引脚以 STM32CubeMX 冲突检查为准，功能需求如下：

| 信号 | 类型 | 功能 |
|---|---|---|
| ADC_ID | ADC | 电池 ID 分压 |
| ADC_NTC | ADC | 电池温度监测 |
| ADC_VBAT | ADC | 电池电压分压 |
| ADC_VOUT | ADC | 无线接收 5V 监测 |
| CHARGER_EN | GPIO | 充电器输入高侧开关 |
| ISET_BOOST | GPIO | 400/800mA 切换 |
| CHG_STAT | GPIO 输入 | 充电状态 |
| POWER_GOOD | GPIO 输入 | 充电输入有效 |
| LED_R | PWM/GPIO | 红色 LED |
| LED_G | PWM/GPIO | 绿色 LED |
| LED_B | PWM/GPIO | 蓝色 LED |
| SWDIO/SWCLK | 调试 | 烧录和调试 |
| UART_TX/RX | 可选 | 日志输出 |
| I2C_SCL/SDA | 可选 | OLED/传感器扩展 |

> RGB LED 需要三个独立 GPIO 或专用 LED 驱动器，不能只用一个 PB1 完成三色独立控制。

### 8.3 ADC 识别电路

```text
3.3V
  │
 R_PULL 10kΩ
  │
  ├──────── ADC_ID
  │
  └──────── 电池包 ID
               │
              R_ID
               │
              P-
```

理想值：

| 电池状态 | R_ID | ADC 电压 |
|---|---:|---:|
| 14500 | 10kΩ | 约 1.65V |
| 18650 | 20kΩ | 约 2.20V |
| 无电池/开路 | ∞ | 约 3.30V |
| ID 短路 | 0Ω | 约 0V |

固件不得只比较单点值，应使用窗口和滞回：

- ID 短路区域；
- 14500 合法窗口；
- 两档之间的禁止区；
- 18650 合法窗口；
- 开路区域；
- 超出窗口均判定为错误。

建议每次识别执行：

- 连续读取至少 16 次；
- 去除最高和最低样本；
- 平均或中值滤波；
- 保持同一结果 300～500ms 后才允许充电。

### 8.4 NTC 链路

硬件 NTC 优先直接连接充电芯片 TS 网络，使 MCU 故障时仍能停止充电。

MCU 可通过以下方式观察温度：

- 高阻分压支路；
- 缓冲器；
- 或增加独立温度传感器。

不得因 MCU ADC 接入改变充电器 TS 的门限。

首版温度策略：

| 电池温度 | 控制策略 |
|---:|---|
| <0°C | 禁止充电 |
| 0～10°C | 仅允许低电流，具体值按电芯数据手册 |
| 10～40°C | 正常 400mA/800mA |
| 40～45°C | 强制 400mA 或暂停 |
| >45°C | 停止充电 |
| 温度采样开路/短路 | 停止充电 |

重新启动必须设置温度滞回，例如温度降低到 42°C 以下后才允许恢复。

## 9. RX 固件状态机

### 9.1 状态定义

```text
POWER_UP       接收到无线电后 MCU 启动
SELF_TEST      检查 ADC、GPIO、状态脚和配置
WAIT_PACK      等待合法电池包
VALIDATE_PACK  验证 ID、NTC、VBAT
READY_LOW      设置 400mA 安全档
CHARGING_LOW   400mA 充电
READY_HIGH     暂停充电并切换为 800mA
CHARGING_HIGH  800mA 充电
DERATING       因温度或 VOUT 下降而降额
FULL           充电完成
FAULT          故障锁定或等待恢复
```

### 9.2 上电逻辑

```text
无线 RX 输出建立
  │
  ▼
MCU 上电，CHARGER_EN 默认保持关闭
  │
  ▼
等待电源稳定 200ms
  │
  ▼
初始化 ADC、GPIO、定时器、看门狗
  │
  ▼
执行自检
  │
  ├─ 自检失败 → FAULT
  │
  ▼
进入 WAIT_PACK
```

### 9.3 电池识别与启动逻辑

```text
WAIT_PACK
  │
  ▼
读取 ID、NTC、VBAT
  │
  ├─ ID 开路 → 保持等待
  ├─ ID 短路/非法 → FAULT
  ├─ NTC 非法 → FAULT
  ├─ VBAT 超范围 → FAULT
  │
  ▼
连续稳定 300～500ms
  │
  ├─ 14500 → 设置 400mA
  │             │
  │             ▼
  │          使能充电
  │             │
  │             ▼
  │        CHARGING_LOW
  │
  └─ 18650 → 先设置 400mA 并使能
                │
                ▼
            观察 VOUT、温度和状态 2～5s
                │
                ├─ 链路不稳定 → 保持 400mA
                │
                └─ 链路稳定 → 暂停充电
                                 │
                                 ▼
                              切换 800mA
                                 │
                                 ▼
                              恢复充电
                                 │
                                 ▼
                           CHARGING_HIGH
```

### 9.4 充电期间监测

建议快速任务每 100ms 执行，慢速任务每 1s 执行。

持续检查：

- ID 是否变化；
- NTC 是否过冷、过热、开路或短路；
- VBAT 是否超压；
- VOUT 是否下跌；
- CHG/PG 状态是否合理；
- 高侧开关输出是否符合预期；
- 看门狗是否正常刷新。

建议 VOUT 策略，最终阈值通过实测调整：

| 条件 | 动作 |
|---|---|
| VOUT ≥4.75V 且稳定 | 允许当前档位 |
| VOUT <4.65V 持续 500ms | 800mA 降至 400mA |
| VOUT <4.40V 持续 200ms | 关闭充电器，等待恢复 |
| VOUT 恢复并稳定数秒 | 从 400mA 重新启动，不直接恢复 800mA |

### 9.5 热降额逻辑

```text
正常充电
  │
  ├─ 电池温度 ≥40°C
  │      ├─ 当前 800mA → 降为 400mA
  │      └─ 当前 400mA → 继续观察
  │
  ├─ 电池温度 >45°C → 停止充电
  │
  └─ 温度恢复到安全滞回值以下 → 从 400mA 重启
```

如增加 PCB 温度传感器，可增加：

- 充电 IC 附近温度 ≥80°C：降额；
- ≥90°C：停充；
- 实际门限须根据传感器位置和芯片结温估算确定。

### 9.6 电池拔出与 ID 变化

充电中出现以下任一条件：

- ID 类型变化；
- ID 进入禁止区；
- ID 开路；
- VBAT 突降；

必须执行：

```text
立即关闭 CHARGER_EN
  │
  ▼
等待至少 100ms
  │
  ▼
恢复默认 400mA 档
  │
  ▼
清除旧电池识别结果
  │
  ▼
返回 WAIT_PACK
```

禁止在充电保持开启时直接切换 ID 类型或 ISET 电阻。

### 9.7 充满逻辑

充满判定主要使用充电芯片状态输出，不由 MCU 自行替代 CC-CV 终止算法。

```text
充电芯片报告终止 / CHG 释放
  │
  ▼
确认 VBAT 接近 4.2V
  │
  ▼
等待去抖
  │
  ▼
进入 FULL
  │
  ├─ 关闭高侧开关或保持充电器自动待机
  ├─ 更新 LED
  └─ 可选通知 BQ51013B 向 TX 发送 Charge Complete/EPT
```

如果后续因电池电压下降需要补充充电，应使用充电芯片自身的再充电机制或由 MCU 从 400mA 档安全重启。

## 10. LED 状态逻辑

推荐 RX RGB LED 定义：

| 状态 | LED 表现 |
|---|---|
| MCU 启动 | 白色短闪一次 |
| 无电池 | 蓝色慢呼吸 |
| 识别到 14500 | 青色闪两次 |
| 识别到 18650 | 蓝色闪两次 |
| 400mA 充电 | 黄色常亮 |
| 800mA 充电 | 绿色常亮 |
| 热降额/链路降额 | 黄色慢闪 |
| 充满 | 绿色呼吸 |
| ID/NTC/VBAT 错误 | 红色快闪 |
| 无线链路不稳定 | 红黄交替 |

TX LED 以所选 TX 控制器的状态定义为准，建议至少区分：

- 待机；
- 正在传输；
- 充电完成；
- FOD/过流/过温故障。

## 11. 保护体系

```text
第 1 层：USB-C 输入
  ├─ CC 合法连接检测
  ├─ ESD/瞬态抑制
  ├─ eFuse 过流/短路
  └─ 输入软启动

第 2 层：TX 功率级
  ├─ 输入电流检测
  ├─ MOSFET/控制器过温
  ├─ Qi FOD
  └─ 通信异常停止传输

第 3 层：RX 控制器
  ├─ 同步整流过压保护
  ├─ 输出限流
  ├─ 热关断
  └─ Qi EPT/故障通信

第 4 层：充电器
  ├─ CC-CV 充电
  ├─ VINDPM/输入能力限制
  ├─ 硬件 NTC
  ├─ 热调节
  └─ 充电终止

第 5 层：MCU
  ├─ ID 合法性检查
  ├─ VBAT 范围检查
  ├─ 温度降额
  ├─ VOUT 降额
  ├─ 超时与状态一致性检查
  └─ 看门狗与故障默认关闭

第 6 层：电池保护
  ├─ 过充
  ├─ 过放
  ├─ 过流
  └─ 短路

第 7 层：机械与材料
  ├─ 非金属充电面
  ├─ 铁氧体屏蔽
  ├─ 电池隔热
  ├─ 阻燃材料
  └─ 防水透气/泄压设计
```

### 11.1 故障默认安全状态

以下情况必须关闭充电器：

- MCU 复位；
- MCU 未烧录；
- 看门狗复位；
- ID 非法；
- NTC 开路/短路；
- VBAT 超范围；
- VOUT 长时间过低；
- 充电状态脚组合不合理；
- 电池类型在充电中变化。

硬件默认状态必须满足：

- CHARGER_EN = OFF；
- ISET_BOOST = OFF；
- 充电电流档位 = 400mA；
- RGB LED 不得反向给 MCU 供电。

## 12. PCB 分区与布局

### 12.1 TX PCB 分区

```text
┌────────────────────────────────────────────┐
│ USB-C │ ESD/CC │ eFuse │ 输入滤波         │
├────────────────────────────────────────────┤
│ TX 控制器 │ 电流采样 │ 状态指示           │
├────────────────────────────────────────────┤
│ Gate Driver / Full Bridge / Resonant Caps  │
├────────────────────────────────────────────┤
│ 线圈连接焊盘                               │
└────────────────────────────────────────────┘

外置叠层：TX 绕线线圈 + 铁氧体片 + 磁铁支架
```

规则：

- 功率桥、谐振电容和线圈连接器形成最小环路；
- 电流采样使用 Kelvin 连接；
- ASK 解调和采样信号远离开关节点；
- 功率地与模拟地按参考设计汇接；
- 不在线圈正下方随意铺大面积铜，具体以铁氧体和参考设计为准；
- 磁铁固定孔不得切断关键回流路径；
- 调试点不得形成长支路天线。

### 12.2 RX PCB 分区

```text
┌────────────────────────────────────────────┐
│ 线圈接口 │ C1/C2 │ BQ51013B               │
├────────────────────────────────────────────┤
│ OUT 电容 │ 3.3V LDO │ STM32 │ SWD/UART    │
├────────────────────────────────────────────┤
│ 高侧开关 │ Charger │ ISET 切换 │ 热过孔    │
├────────────────────────────────────────────┤
│ 保护电路/电池接口 │ ID/NTC │ RGB LED      │
└────────────────────────────────────────────┘

外置叠层：RX 绕线线圈 + 铁氧体片
```

规则：

- AC1/AC2、C1/C2 和 BQ51013B 走线最短；
- RECT/OUT 电容紧贴芯片；
- BQ51013B 暴露焊盘使用完整地铜和热过孔；
- 充电器功率回路靠近电池接口；
- ID、NTC、ADC 线远离 AC1/AC2 和开关节点；
- ADC 输入增加适当 RC 滤波；
- SWD 必须保留；
- 预留 VRECT、VOUT、3V3、VBAT、ID、NTC、CHG、PG、CHARGER_EN、ISET_BOOST 测试点；
- 电池 NTC 不得紧邻充电 IC；
- 线圈和电池之间使用铁氧体及绝缘层，不让电池金属壳直接暴露于强交变磁场。

## 13. 密封与热设计

### 13.1 外壳原则

可选材料：

- ABS/PC；
- PA12，但需要封孔/涂层；
- 工程树脂，但需要评估脆性和温度；
- 陶瓷窗口，仅作为进阶方案。

首版推荐：

- 螺钉锁合；
- O 形圈或闭孔泡棉密封圈；
- 充电面一体化薄壁；
- PCB 三防漆；
- 暂不全灌封，便于返修和热测试。

### 13.2 热路径

允许的散热方式：

- 充电 IC 暴露焊盘到 PCB 内外层铜；
- 热过孔；
- 在线圈有效区之外布置铜质散热区；
- 通过外壳非充电面传热；
- 在铁氧体背面、经过电磁验证后使用屏蔽/扩散结构。

禁止：

- 在线圈和另一侧线圈之间加入铝箔；
- 在线圈后直接贴未验证的连续铜片或钢片；
- 让电池金属壳紧贴无线线圈且无铁氧体隔离；
- 仅依赖芯片内部热保护作为正常温控手段。

### 13.3 泄压

包含锂电池的“密封仓”不应被理解为绝对气密容器。

正式结构建议：

- 使用防水透气膜或定向泄压结构；
- 避免电池异常排气导致壳体压力积聚；
- 电池与 PCB 热源保持隔离；
- 选择阻燃或自熄材料；
- 电池不可被螺钉、磁铁或尖锐结构挤压。

## 14. 预期性能

### 14.1 充电时间估算

| 电池 | 容量 | 充电电流 | 理想 CC 时间 | 含 CV 阶段预计总时间 |
|---|---:|---:|---:|---:|
| 14500 | 800mAh | 400mA | 约 2.0h | 约 2.5～3.0h |
| 18650 | 2500mAh | 800mA | 约 3.1h | 约 3.8～4.5h |

实际时间受以下因素影响：

- 电芯真实容量；
- 起始电量；
- 线圈对准；
- 外壳间距；
- 温度降额；
- CV 阶段持续时间；
- 无线链路是否触发 VINDPM。

### 14.2 首版性能目标

| 项目 | 目标 |
|---|---|
| USB 输入 | 5V/2A |
| RX 输出 | 对准时 5V，持续负载至少 0.8A |
| 14500 电流 | 400mA ±10% |
| 18650 电流 | 800mA ±10% |
| 满充电压 | 4.20V ±1% |
| 总机械间距 | 优先 ≤2.5mm，最大约 3mm |
| 横向偏移演示 | ±3mm 内不失控、不异常发热 |
| 电池表面温度 | 正常充电尽量 <45°C |
| 可触外壳温度 | 正常环境下尽量 <50°C |
| 满载连续运行 | 密封装配后至少 2h，无周期性掉电或热保护振荡 |
| ID 故障 | 开路、短路、超范围均不得进入 800mA |
| 异物 | 系统停止或显著限功率，不持续危险升温 |

上述指标是工程目标，不代表认证指标。

## 15. 调试与验证路径

### 阶段 1：无线链路基准验证

使用成熟 TX 模块/EVM 和成熟 RX EVM/模块：

1. 验证 5V 空载输出；
2. 使用电子负载逐步增加至 0.2A、0.4A、0.8A、1.0A；
3. 测量 TX 输入功率、RX 输出功率和温升；
4. 测试 0～3mm 间距；
5. 测试横向偏移；
6. 测试磁铁加入前后差异。

只有基准链路稳定后才开始自研 RX PCB。

### 阶段 2：自研 RX 前端验证

暂不连接电池和充电器：

1. BQ51013B OUT 接电子负载；
2. 验证启动、通信和稳定输出；
3. 调整 C1/C2；
4. 校准 FOD；
5. 验证 VOUT 跌落和过流行为；
6. 验证 PCB 温升。

### 阶段 3：充电管理验证

先使用电池模拟器或实验电源模拟电池：

1. 验证 400mA 档；
2. 验证 800mA 档；
3. 验证先停充再切档；
4. 验证 CC-CV 曲线；
5. 验证满充终止；
6. 验证 NTC 开路、短路、过冷、过热；
7. 验证 VINDPM 降流；
8. 验证 MCU 复位时充电器默认关闭。

### 阶段 4：真实电池验证

1. 首先使用带保护的已知品牌电芯；
2. 电源设置硬件限流；
3. 先从 400mA 验证；
4. 全程记录 VBAT、ICHG、VOUT 和温度；
5. 确认终止电压后再验证 800mA；
6. 至少完成多次完整充放电循环。

### 阶段 5：结构与密封验证

1. 安装最终外壳；
2. 重新测量线圈电感；
3. 必要时重新调整 C1/C2；
4. 进行满载 2h 温升；
5. 进行偏移、间距和倾角测试；
6. 进行磁铁吸附和拉脱测试；
7. 进行泼水/短时浸水等原型级密封测试；
8. 重新进行 FOD 与金属异物测试。

## 17. 比赛展示逻辑

建议答辩演示顺序：

1. 展示密封设备没有外露充电触点；
2. TX 与 RX 磁吸自动对准；
3. 系统识别 14500 电池包并进入 400mA；
4. 更换 18650 电池包，系统先以 400mA 安全启动；
5. 链路稳定后自动提升至 800mA；
6. 人为稍微错位，系统检测 VOUT 下降并降回 400mA；
7. 加热或模拟 NTC，系统执行热降额/停充；
8. 电池充满后状态灯变化并通知 TX 停止持续传输；
9. 展示效率、温升、间距和偏移测试数据。

项目核心表述：

> 系统利用标准 Qi 功率链路解决密封设备的非接触供电问题，并结合电池包身份、无线链路能力和电池温度三类信息，自适应选择安全充电电流。

**V2.0 总结**：首版产品应采用成熟 Qi TX、标准绕线线圈、BQ51013B 同步整流 RX、原生 4.2V 充电管理和 400mA/800mA 故障安全切换。STM32 不参与底层 Qi 协议，只负责电池识别、温度/链路监测、充电调度和人机状态展示。整个系统的优先级依次为：安全、稳定、可测试、可展示，最后才是效率和小型化。
